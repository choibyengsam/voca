# 한국 생사 확인 앱 시장 진출 전략 및 기획서

## Executive Summary

본 문서는 중국에서 성공한 "死了么(Demumu)" 앱의 한국 시장 진출 전략을 담고 있습니다. 한국은 세계 최고 수준의 고령화 속도, 1인 가구 급증, 높은 스마트폰 보급률을 갖춘 시장으로, 생사 확인 앱의 높은 잠재력을 보유하고 있습니다.

**핵심 전략**: B2C 앱 출시 → B2G 지자체 협력 → B2B 요양/돌봄 시장 확장

```typescript
// 카카오 알림톡 발송 예시
interface KakaoAlimtalkRequest {
  template_code: string;
  recipient_list: {
    recipient_no: string;
    template_parameter: {
      userName: string;
      checkInTime: string;
      lastCheckIn?: string;
    };
  }[];
}

async function sendKakaoAlimtalk(
  type: 'checkin' | 'warning' | 'emergency',
  recipient: string,
  params: Record<string, string>
): Promise<void> {
  const templateCodes = {
    checkin: 'ANSIMTALK_CHECKIN_001',
    warning: 'ANSIMTALK_WARNING_001',
    emergency: 'ANSIMTALK_EMERGENCY_001'
  };

  await kakaoApi.send({
    template_code: templateCodes[type],
    recipient_list: [{
      recipient_no: recipient,
      template_parameter: params
    }]
  });
}

// 체크인 완료 시 알림 발송
async function onCheckInComplete(user: User): Promise<void> {
  const familyMembers = await getFamilyMembers(user.id);

  for (const member of familyMembers) {
    await sendKakaoAlimtalk('checkin', member.phone, {
      userName: user.name,
      checkInTime: formatTime(new Date()),
      relationship: member.relationship
    });
  }
}
```

1. **시장 기회 명확**: 한국은 세계 최고 수준의 고령화 + 스마트폰 보급률로 최적의 시장
2. **경쟁 공백 존재**: "간단 + 저렴 + 모바일" 영역에 직접 경쟁자 부재
3. **카카오 연동 필수**: 한국 시장 성공의 핵심은 카카오톡 알림톡
4. **B2G 확장 유리**: 정부 고독사 예방 정책과 연계 가능
5. **자녀→부모 모델**: 자녀가 설치해드리는 "효도 앱" 포지셔닝 유효
